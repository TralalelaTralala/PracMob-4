# Консольні результати

Файли `.txt` у цій папці містять вивід Dart-програм і тестів. `screenshots/task1_variables.png`–`task5_async.png` — справжні знімки вікна PowerShell із запуском програм, надані користувачем. `screenshots/quality_checks.png` поки що сформований зі збережених логів і не є сирим знімком екрана.

Скрипт `scripts/render_evidence.ps1` формує лише зображення `quality_checks.png` зі збережених логів; він не перезаписує справжні скриншоти програм. `task5_async_output.txt` і `data/async_report.json` містять результати вимірювання часу.

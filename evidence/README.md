# Консольні результати

Файли `.txt` у цій папці містять фактичний вивід Dart-програм і тестів. Це текстові логи, а не скриншоти.

Щоб зробити потрібні скриншоти на своєму комп'ютері, відкрийте PowerShell у корені проєкту, виконайте команди `dart run bin/taskN_*.dart` з `README.md` та зніміть вікно термінала через Snipping Tool. `task5_async_output.txt` і `data/async_report.json` містять результати вимірювання часу.
